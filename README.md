# Guía de Seguridad Informática

Sitio de estudio para preparar preguntas de desarrollo a partir de los 15 documentos compartidos. Incluye temario explicado, búsqueda, filtros, ejemplos, pistas de examen y respuestas modelo.

## Abrirlo en el ordenador

Abre `index.html` con un navegador. No necesita instalación ni dependencias.

## Subirlo a GitHub

1. Descomprime el ZIP y crea un repositorio nuevo en GitHub.
2. Sube el contenido de esta carpeta al nivel principal del repositorio. Deben quedar `index.html` y la carpeta `dist` juntos.
3. Para publicarlo con GitHub Pages, entra en **Settings → Pages**, selecciona la rama `main` y la carpeta `/(root)`, y guarda.

El archivo principal y sus recursos están preparados para funcionar también bajo la ruta de un repositorio de GitHub Pages.

## Añadir los PDF originales

Los PDF no están dentro del ZIP. Las fichas mantienen un enlace a tus archivos de ChatGPT Library. Si quieres que los PDF también se abran desde una web de GitHub, añade una carpeta `dist/pdfs` y coloca dentro los documentos con estos nombres. Las fichas mostrarán automáticamente un segundo enlace cuando detecten cada archivo.
